# vefa-simulator
VEFA Loan Simulator.

Simulates your VEFA Purchase (France), calculates credit options (incl. PTZ) and cost, includes negotiation recommendations, avg. cost m² comparison, and detailed payment plan options throughout the VEFA program stages. Allows for plans, brochures and contact info storage (Local only) and multiple project management via dropdown selection. 

Try it here: https://zedcade.github.io/vefa-simulator/
